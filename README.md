# syncwave
Repositorio del grupo syncwave

MarketTech AI 

MarketTech AI es un proyecto académico desarrollado con Python que busca recopilar, organizar y analizar los precios de componentes de computadoras comercializados en Panamá.

El proyecto surge ante la dificultad de encontrar información centralizada que permita comparar precios entre comercios y conocer cómo evolucionan los costos de los componentes tecnológicos a lo largo del tiempo.

Mediante herramientas de procesamiento de datos e inteligencia artificial, se busca facilitar el acceso a información organizada y contribuir a que los consumidores tomen decisiones de compra más informadas.
